# Music

By default the pipeline uses **procedural music**: an original beat generated from code for every
video (different tempo, key, chord progression and pattern each time). It is owned by you, so there
are no licence questions.

To use your own tracks instead, add the audio files here, describe each one in `LICENSES.yaml`
(licence + allowed platforms) and set `music.mode: licensed` in `config/settings.yaml`.
Unlisted files are ignored.
